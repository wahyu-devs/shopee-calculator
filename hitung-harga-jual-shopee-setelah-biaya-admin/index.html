Cara Hitung Harga Jual Shopee Setelah Biaya Admin

Kalau kamu ingin tahu harga yang harus dipasang setelah biaya admin dipotong, jangan berhenti di satu persentase saja. Di banyak kasus, seller juga perlu memasukkan biaya layanan dan biaya proses pesanan supaya uang bersih yang diterima benar-benar sesuai target.

Hitung di kalkulator Lihat rumus lengkap

Rumus yang dipakai

Untuk menghitung harga jual minimum, jumlahkan dulu target uang bersih dengan biaya tetap per pesanan. Setelah itu, bagi dengan sisa persentase yang tersisa setelah biaya admin dan layanan.

Harga jual minimum = (target uang bersih + biaya proses) / (1 - admin - layanan)
Catatan: angka admin, layanan, dan proses pesanan bisa berbeda antar program seller. Angka di bawah ini hanya contoh berdasarkan default kalkulator saat ini.

Contoh hitung dengan target bersih Rp100.000

Komponen Nilai
Target uang bersih Rp100.000
Biaya admin 8,25%
Biaya layanan 5,5%
Biaya proses pesanan Rp1.250
  1. 1
    Jumlahkan target uang bersih dan biaya proses: Rp100.000 + Rp1.250 = Rp101.250
  2. 2
    Hitung sisa persentase setelah biaya admin dan layanan: 1 - 0,0825 - 0,055 = 0,8625
  3. 3
    Bagi Rp101.250 dengan 0,8625 sehingga hasil kasarnya sekitar Rp117.391
  4. 4
    Untuk harga jual aman, seller biasanya membulatkan ke atas. Di kalkulator ini hasilnya menjadi Rp117.400

Kapan hasil ini perlu dinaikkan lagi

  • Saat kamu menanggung voucher toko atau subsidi diskon.
  • Saat produk juga butuh menutup biaya iklan, affiliate, atau packing tambahan.
  • Saat ingin menambahkan buffer margin agar harga tidak pas-pasan.

Kenapa seller sering salah hitung?

Kesalahan yang paling sering terjadi adalah mengurangi biaya admin langsung dari target laba, padahal biaya berbentuk persentase dipotong dari harga jual. Karena itu, hasil manual sering meleset kalau tidak dihitung dengan formula yang tepat.

Butuh hitung cepat?

Gunakan kalkulator untuk mengubah target uang bersih menjadi harga jual minimum tanpa menghitung manual berulang kali.
